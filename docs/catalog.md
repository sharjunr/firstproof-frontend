Browse by field or major, use the natural-language keyword search (including roles, jobs, HR, arts, and healthcare phrasing), and navigate 12 results per page. Filters reset pagination. Search matches word boundaries so AI does not accidentally match text such as explain.

Existing saved browser state is upgraded by adding missing catalog IDs. Existing edited listings, drafts, submissions, notes, saved opportunities, and custom employer posts are preserved. Repeated upgrades do not duplicate entries.

Verification: 13 automated tests cover seed coverage and unique briefs, search across disciplines, word-boundary behavior, preserved browser-state data during upgrades, and existing application workflows.
